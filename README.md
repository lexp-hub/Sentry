Sentry is an open-source, privacy-first Discord security and moderation bot paired with a standalone monospace web dashboard. It features neural AI integration (Llama 3.3 70B), automatic partnership management, a live column-based embed builder, reaction roles, and automated moderation tools.

### Features

- **Automated moderation**: Anti-link, anti-invite, anti-spam, word filters, and audit logging.
- **Interactive web dashboard**: High-density dark monospace control panel with WebSocket live sync.
- **Visual embed builder**: Real-time Discord markdown preview with multi-column layout support.
- **Partnership system**: Automated modal submission, invite validation, and manager leaderboard tracking.
- **Community tools**: Reaction roles, ticket system, custom welcomer, leveling, and minigames.

For detailed architecture, slash commands reference, module workflows, and headless API endpoints, see [DOCUMENTATION.md](DOCUMENTATION.md).
