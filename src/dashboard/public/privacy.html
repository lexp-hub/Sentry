Privacy Policy

This Privacy Policy transparently explains how Sentry ("we", "the Bot", "the Application") collects, uses, stores, and protects user and server data across Discord and Yapin, in accordance with EU Regulation 2016/679 (GDPR) and platform developer policies.

1 Data Minimization Principle

Sentry operates under the core principle of strict data minimization: we retain only the technical identifiers essential to execute the requested operational features for servers and users.

We never collect sensitive personal information, banking credentials, physical addresses, phone numbers, or private emails.

2 Data We Collect

[ID] Public Identifiers:

User ID, Server/Guild ID, Channel ID, and Role ID. These numerical IDs uniquely identify entities to associate configurations, permissions, and moderation logs.

[Config] Server Configuration Data:

Welcome channels, log channels, reaction roles, command prefixes, partnership counters, and temporary voice configurations saved via the Dashboard.

[AFK] User Status Data (AFK Module):

When a user runs /afk [reason], we temporarily record user ID, textual reason, and timestamp. This record is immediately erased as soon as the user returns and chats.

[Games] Entertainment & Leveling Data:

Experience points (XP), levels, virtual economy balances, and minigame scores (Blackjack, Fishing, Dice). These metrics possess zero monetary value.

3 Message Content & Ephemeral Processing

No Permanent Message Storage: Sentry DOES NOT store, log, or persist user chat text in any permanent database.

The Message Content intent is used strictly for real-time in-memory analysis and is immediately discarded:

  • AFK Detection: Checks if a user mentioned an absent member to send a notice.
  • AI Assistant: Immediate inference when Sentry is mentioned or queried via /ai.
  • AutoMod & Invites: Immediate scan for unauthorized links, spam floods, and blacklisted phrases.

4 Storage & Data Security

All stored configuration records reside in encrypted, secured databases protected by firewalls, TLS/HTTPS transport encryption, and restricted administrator-only access.

Data is maintained as long as Sentry remains installed on the server or until an explicit deletion request is received.

5 Third-Party Services

Your data is never sold, rented, or transferred for commercial or advertising purposes. Interactions with third parties occur solely for essential service delivery:

  • Discord & Yapin APIs: For event dispatching, role provisioning, and real-time message handling.
  • Cloudflare Workers AI: Neural query processing for Sentry AI prompts. Data is not used to train public foundational models.

6 Your Rights (GDPR Access & Erasure)

Under Articles 15-22 of EU Regulation 2016/679 (GDPR), every user and administrator has the right to:

  • Right of Access: Request disclosure of all configuration and data associated with your ID.
  • Right to Erasure (Right to be Forgotten): Request complete and permanent deletion of your data (levels, economy, logs, server configs).
  • Right to Rectification: Modify or update configurations anytime through commands or the Web Dashboard.
[Contact] How to request data deletion:

To request total data erasure, open a support ticket or contact the application developer directly. All verified requests are processed within 48 business hours.

7 Policy Updates

We may update this Privacy Policy from time to time to reflect operational or regulatory changes. In the event of material revisions, prominent notice will be displayed on the Web Dashboard.
